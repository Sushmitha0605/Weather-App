# Weather App

## Overview

The Weather App is a responsive web application that provides real-time weather information for cities around the world using the OpenWeather API. It allows users to search for locations, view current weather conditions, and access a 12-hour forecast through a clean and interactive interface.

---

## Features

- Real-time weather information
- City search with autocomplete suggestions
- 12-hour weather forecast
- Temperature display in Celsius
- Weather condition icons
- Humidity and wind speed
- Sunrise and sunset timings
- Responsive and modern user interface

---

## Technologies Used

- HTML
- CSS

- OpenWeather API

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Weather-App.git
```

### 2. Navigate to the project folder

```bash
cd Weather-App
```

### 3. Get an OpenWeather API Key

Create a free account at:

https://openweathermap.org/api

Generate an API key.

### 4. Replace the API key

Open `script.js` and replace:

```javascript
const apiKey = "YOUR_OPENWEATHER_API_KEY";
```

with your own API key.

### 5. Run the application

Simply open `index.html` in your web browser.
